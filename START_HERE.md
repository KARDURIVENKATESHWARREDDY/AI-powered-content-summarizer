## 🚀 Option 2: Run On Your Computer (5 minutes)

### On Windows:
```bash
# 1. Open Command Prompt in project folder
# 2. Create environment
python -m venv venv

# 3. Activate it
venv\Scripts\activate

# 4. Install & run
pip install -r requirements.txt
streamlit run streamlit_app.py
```

### On Mac/Linux:
```bash
# 1. Create environment
python -m venv venv

# 2. Activate it
source venv/bin/activate

# 3. Install & run
pip install -r requirements.txt
streamlit run streamlit_app.py
```

## 🆘 Troubleshooting

| Problem | Solution |
|---------|----------|
| "Python not found" | Install Python from python.org |
| "Port already in use" | Use port 8502: `streamlit run streamlit_app.py --server.port 8502` |
| Slow first run | Normal! Models download first time (5-15 min) |
| Out of memory | Use lightweight model: DistilBART |

See full troubleshooting in [QUICK_START.md](QUICK_START.md#troubleshooting)
